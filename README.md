# A2ZInvoices — Android Java

نسخة Android Native مكتوبة بالكامل بلغة **Java**، محولة من مشروع WPF/C# المرفق.

## الوظائف
- تحرير الفواتير.
- حفظ الزبائن والممونين والسلع.
- معلومات الشركة.
- حساب المجموع، TVA، والطابع الجبائي.
- حفظ الفواتير محلياً داخل التطبيق.
- إنشاء PDF بمقاس A4.
- جدول الفاتورة مضبوط **يمين ← يسار** بشكل صريح: رقم، التعيين، الوحدة، الكمية، سعر الوحدة، المجموع.
- كتابة المبلغ بالحروف العربية.
- فتح PDF أو مشاركته.

## بناء APK على GitHub
1. أنشئ Repository جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى الفرع `main`.
3. افتح تبويب **Actions**.
4. شغّل **Build A2ZInvoices APK** بواسطة `Run workflow`، أو ادفع commit جديداً.
5. بعد انتهاء البناء افتح نتيجة الـ workflow وحمّل artifact باسم `A2ZInvoices-debug-apk`.
6. ستجد داخله `app-debug.apk`.

لا يحتاج المشروع إلى Flutter أو Kotlin.
